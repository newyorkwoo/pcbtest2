# outdoor_hmi 1:1 試裝（2026-11-13）

`outdoor_hmi_testfit_1to1.pdf`：F.Mask（焊盤開窗 + 實際鑽孔形狀）、F.Fab、板框，A4 1:1。

1. 以「實際大小 / 100%」列印，關閉「縮放至頁面」。
2. 量板框寬度，必須是 **80.0 mm**（高 48.0 mm），誤差超過 ±0.3 mm 就重印。
3. 把紙貼在 1.6 mm 以上的泡棉板或紙板上，用針刺穿鑽孔位置。

| 零件 | 檢查 | 依據 |
|---|---|---|
| SW6 Alps EC12D1524403 | 5 支端子（A/B/C 與開關 D/E）能同時插入 ø1.05 孔；兩個固定腳能進 2.05×2.15 橢圓槽（原廠圖是矩形孔，注意固定腳對角會不會卡） | Alps EC12E/EC12D 型錄，圖號 No.5 |
| D4 Broadcom CSMW-LR00-ATV0E | 本體 3.5×2.8 放在焊盤上，**陽極標記（缺角）朝大焊盤**（pad 2，在 SW6 那一側） | CSMW-Lx00-AxxxE-DS100 Fig.1 / Fig.12 |

孔位座標已逐一用原廠圖核對過；實際試裝是要確認公差，以及固定腳能不能插進橢圓槽。
